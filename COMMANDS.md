# Commands beyond the everyday ones

The everyday commands (tests, the parse check, the import, a quick run, the backend's tests) are in `CLAUDE.md`. This is the rest: the web build, the videos, the screenshot scripts and what each writes, every art and sound tool, and the cover. Read a row before running it: most open a window or write into `Assets/`, and a deploy is only ever the user's to ask for.

Arguments that start with `--path` go to Godot's console build (`C:\Users\Dik\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe`); everything else is run from the project folder as written. Every Python tool answers `--help` without doing anything and turns away an argument it does not know; what they need beyond Python is in `requirements.txt` (`pip install -r requirements.txt`, plus ffmpeg and, for `AI-sprites-generator/build.py`, Aseprite).
